# Phase 7 Edge-Case Register — Fees, HR, Payroll & Accounting

Phase 7.12 deliverable (Master Plan §4A). One 8-field record for every row of the
Phase 7 plan §2 register, plus the defects found during 7.12.

**Status key**

- **HT**: handled, with an automated test as evidence.
- **INV**: impossible by a database invariant (constraint or trigger), with a direct-SQL test.
- **DEF**: deliberately deferred. The record names the owner decision or the later phase.
- **NP**: the feature does not exist by decision, so the edge case cannot arise. It becomes live if the feature is added.

**Conventions**

- Test files are under `apps/api/` unless the path starts with `apps/web/`.
- `int` means a PostgreSQL 16 integration suite (`test/*.int-spec.ts`).
- A quoted name is the exact test title.
- "Audit" means an `AuditLog` row written in the same transaction as the change.
- "409 code" means the API answers `409 Conflict` with that stable reason code.

Baseline for this register: `main` at the 7.12 commit. Every status was re-checked against the
code and the tests at that commit, not copied from the plan.
